# I18n 国际化

Spring Boot 的国际化（I18n，Internationalization）由两部分组成：

- **MessageSource** — 根据 code + Locale 翻译文本
- **LocaleResolver** — 解析当前请求使用哪个 Locale

## 一、资源文件

### 命名规则

```
messages.properties           ← 默认语言（通常为英文）
messages_zh_CN.properties     ← 中文（中国）
messages_ja_JP.properties     ← 日文（日本）
```

`_语言_地区` 后缀说明：

| 文件 | Locale 常量 |
|---|---|
| `messages.properties` | `Locale.ENGLISH` / 无匹配时的回退 |
| `messages_zh_CN.properties` | `Locale.CHINA` / `Locale.SIMPLIFIED_CHINESE` |
| `messages_ja_JP.properties` | `Locale.JAPAN` |

### 内容格式

```properties
# key=value
welcome=Welcome
user.greeting=Hello, {0}!
order.status=Order status: {0}
```

`{0}`、`{1}` 是占位符，运行时替换为传入的参数。

### 常见问题：`fallback-to-system-locale`

默认情况下 `ResourceBundleMessageSource` 在找不到请求语言的资源文件时，**先回退到系统 Locale**，而不是默认文件。如果服务器系统 locale 是 `zh_CN`，请求 `Locale.ENGLISH` 时会先匹配到 `messages_zh_CN.properties`。

**解决方案**：在 `application.properties` 中关闭此行为：

```properties
spring.messages.fallback-to-system-locale=false
```

关闭后，找不到 `messages_en.properties` 就直接走 `messages.properties`（默认文件）。

## 二、配置

### application.properties

```properties
spring.messages.basename=i18n/messages          # 资源文件路径，不含后缀
spring.messages.cache-duration=3600             # 缓存时长（秒），默认永久
spring.messages.fallback-to-system-locale=false # 禁止回退到系统 Locale
spring.messages.encoding=UTF-8                  # 编码，默认 UTF-8
```

### 使用 @Bean 手动配置（替代自动配置）

```java
@Bean
MessageSource messageSource() {
    ReloadableResourceBundleMessageSource source = new ReloadableResourceBundleMessageSource();
    source.setBasename("classpath:i18n/messages");
    source.setDefaultEncoding("UTF-8");
    source.setFallbackToSystemLocale(false);
    return source;
}
```

## 三、MessageSource 使用

### 注入

```java
@Autowired
private MessageSource messageSource;
```

### 核心方法

| 方法 | 说明 |
|---|---|
| `getMessage(code, args, locale)` | 按 code + Locale 翻译，找不到抛 `NoSuchMessageException` |
| `getMessage(code, args, defaultMsg, locale)` | 找不到时返回 `defaultMsg` |

### 示例

```java
// 指定 Locale 翻译
messageSource.getMessage("welcome", null, Locale.CHINA);       // → "欢迎"

// 带占位符
messageSource.getMessage("user.greeting", new Object[]{"Tom"}, Locale.JAPAN);
// → "Tomさん、こんにちは！"

// 找不到时提供默认值
messageSource.getMessage("unknown", null, "默认", Locale.CHINA);  // → "默认"

// 找不到且无默认值 → 抛异常
messageSource.getMessage("unknown", null, Locale.CHINA);
// → NoSuchMessageException
```

### LocaleContextHolder（线程级绑定）

无需在每个调用中传递 Locale，绑定到当前线程即可：

```java
Locale original = LocaleContextHolder.getLocale();
try {
    LocaleContextHolder.setLocale(Locale.JAPAN);
    messageSource.getMessage("order.status", new Object[]{"paid"});
} finally {
    LocaleContextHolder.setLocale(original);
}
```

注意：`getMessage(code, args)` 这个无 Locale 参数的重载 `getMessage(code, args, locale)` 的区别：

| 重载 | Locale 来源 |
|---|---|
| `getMessage(code, args, locale)` | 显式传入 |
| `getMessage(code, args)` | 从 `LocaleContextHolder` 自动获取 |

## 四、LocaleResolver（区域解析）

决定当前请求使用哪个 Locale 的策略：

| 实现类 | 数据来源 | 使用场景 |
|---|---|---|
| `AcceptHeaderLocaleResolver` | HTTP 请求头 `Accept-Language` | 浏览器自动发送，**默认策略** |
| `CookieLocaleResolver` | Cookie | 用户手动切换语言，持久化 |
| `SessionLocaleResolver` | HttpSession | 用户手动切换语言，仅会话内有效 |
| `FixedLocaleResolver` | 固定值 | 不支持多语言的场景 |

### AcceptHeaderLocaleResolver

从请求头 `Accept-Language` 解析：

```java
AcceptHeaderLocaleResolver resolver = new AcceptHeaderLocaleResolver();

MockHttpServletRequest request = new MockHttpServletRequest();
request.addHeader("Accept-Language", "zh-CN,zh;q=0.9");
resolver.resolveLocale(request);   // → zh_CN

// 无请求头时设置默认值
resolver.setDefaultLocale(Locale.JAPAN);
resolver.resolveLocale(new MockHttpServletRequest());  // → ja_JP
```

### CookieLocaleResolver

从 Cookie 中读写 Locale：

```java
CookieLocaleResolver resolver = new CookieLocaleResolver();

// 读取
request.setCookies(new Cookie("locale", "ja_JP"));
resolver.resolveLocale(request);    // → ja_JP

// 写入（Cookie 名因 Spring 版本可能不同，不依赖名字，通过 response.getCookies() 获取）
resolver.setLocale(request, response, Locale.CHINA);
jakarta.servlet.http.Cookie cookie = response.getCookies()[0];
cookie.getValue();   // → "zh_CN"
request.setCookies(cookie);
resolver.resolveLocale(request);    // → zh_CN
```

Cookie 名默认为 `locale`，可通过 `setCookieName()` 修改。

### SessionLocaleResolver

从 HttpSession 属性中读取 Locale：

```java
SessionLocaleResolver resolver = new SessionLocaleResolver();

request.getSession().setAttribute(
    SessionLocaleResolver.LOCALE_SESSION_ATTRIBUTE_NAME, Locale.US);
resolver.resolveLocale(request);   // → en_US
```

### 注册自定义 LocaleResolver

```java
@Configuration
public class WebMvcConfig implements WebMvcConfigurer {

    @Bean
    public LocaleResolver localeResolver() {
        CookieLocaleResolver resolver = new CookieLocaleResolver();
        resolver.setDefaultLocale(Locale.CHINA);
        resolver.setCookieMaxAge(86400); // 一天
        return resolver;
    }
}
```

如不注册，Spring Boot 默认使用 `AcceptHeaderLocaleResolver`。
